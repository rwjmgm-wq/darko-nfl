WHAT THE JOBS DO
================================================================================

Job 1: fetch_historical_sp_plus_retry.py
- Fetches SP+ opponent strength ratings (2003-2023)
- Retries every 10 minutes if it hits API errors
- Saves progress incrementally
- Will run until all 21 years are collected

Job 2: collect_full_college_careers_retry.py
- Fetches full college career play-by-play for all 124 QBs
- Retries every 30 minutes if it hits API errors
- Saves progress incrementally (QB by QB)
- Will run until all 124 QBs are collected

Both scripts will automatically retry when they hit errors, so you can leave
them running overnight. They save progress as they go, so they won't lose
work if interrupted.


MONITORING PROGRESS
================================================================================

The terminal windows will show:
- Current attempt number
- How many years/QBs have been collected
- Percentage complete
- When the next retry will occur (if blocked)

You can safely close the windows to stop the jobs. Progress is saved,
so they'll resume where they left off when restarted.
