# LEAF v3.4 Re-Certification

Generated by `scripts/v3_4/evaluate_v34.py`. This is a NEW document; v3 results in `docs/LEAF_V3_RESULTS.md` are untouched.

## Headline verdict

1. **Forecast-origin interval calibration is materially improved, and is reported as such only for Mode A.** Nominal 80% coverage is 80.0% (PIT KS 0.084) using only origin-time information, versus 31.5% for v3's state-variance-only intervals. The Mode B figures elsewhere in this document are retrospective diagnostics and are NOT evidence that a deployable interval is calibrated.

2. **The fused rating ranks below the un-fused informed state, but this is SUGGESTIVE, not confirmatory.** Δr = -0.0259; primary QB-clustered 95% CI [-0.059, +0.006] includes zero. The season-clustered CI [-0.046, -0.003] rests on only 7 clusters and is a sensitivity check, not a basis for a decisive claim. Leave-one-season-out Δr ranges [-0.0337, -0.0202].

3. **Fused still leads on level, not order** (best RMSE/MAE among the scored predictors), consistent with v3.

4. **Not comparable to v3's published table.** The population changed (regular season only, QB passers only), so the targets differ. No v3-vs-v3.4 improvement is claimed.

### Consequence for Phase 2

The exporter labels the fused column as "leaf_rating" while the dashboard forecasts from `k_informed`. That mismatch remains unresolved and is Phase 2 work. Phase 2 must deploy Mode A intervals only.

### Fusion target definitions — both reported, neither selected on frozen data

The deployed fit uses a DENSE target (span ≤ 730 days, n = 595 pairs). Reason the rule exists: v3's "next 16 games" is really "next 16 APPEARANCES", and for QBs with long inactive stretches that window reached 4,375 days (12 years) — a label that is not a short-horizon forecast in any useful sense. The unrestricted clean fit is reported above as a separate row. **The choice between them was made on definitional grounds before scoring, not by comparing 2019–2025 outcomes.** Any sensitivity of the 730-day threshold must be explored on training-era data only.

## Predictive intervals — two explicitly separate modes

### Mode A — `forecast_origin` (deployable)

Uses only information available at the forecast origin. The sampling-noise term uses the training-era expectation E[1/plays] = 0.002454 (implied ≈ 407 plays); realized future volume is never read. The variance scale is fit to rolling out-of-fold TRAINING residuals (n = 203, seasons 2012–2018), which absorbs fusion-coefficient uncertainty, CPOE/success state error and their covariance jointly — no independence assumption is asserted.

### Mode B — `conditional_realized_volume` (RETROSPECTIVE DIAGNOSTIC ONLY)

**Not deployable.** These intervals use the realized next-season play count, which no forecast can know at the origin. Reported only to show how much of the interval width is attributable to volume uncertainty.
