# LEAF v3.4 Re-Certification

Generated by `scripts/v3_4/evaluate_v34.py`. This is a NEW document; v3 results in `docs/LEAF_V3_RESULTS.md` are untouched.

## What changed vs v3

## Headline verdict

1. **Interval calibration is repaired.** Nominal 80% coverage moves from 31.5% (state variance only, the v3 behaviour) to 85.5% with the full predictive interval. PIT KS = 0.097. Slight over-coverage remains; the interval is now conservative rather than badly overconfident.

2. **The fusion layer no longer earns its place on ranking.** With the label leakage removed, LEAF v3.4 fused (r = +0.4353) ranks BELOW the un-fused informed state (r = +0.4612); Δr = -0.0259, 95% CI [-0.057, +0.005] clustered by QB and [-0.044, -0.003] clustered by season — the season-clustered interval excludes zero. Part of v3's apparent fusion benefit came from the 92 training pairs whose targets reached into the frozen era.

3. **Fused still wins on level, not order.** It has the best RMSE, MAE and CRPS of every predictor scored here, consistent with v3's finding that the machinery earns its keep on calibration rather than ranking.

4. **Do not compare these numbers directly to v3's published table.** The population changed (regular season only, QB passers only), so the targets themselves differ. This document re-certifies the corrected pipeline; it is not a v3-vs-v3.4 horse race on identical data.

### Consequence for Phase 2

The exporter labels `leaf_v3` as "leaf_rating" while the dashboard forecasts from `k_informed`. On this evidence the dashboard's choice of mean is the better ranking predictor, but the mismatch is undocumented and unevaluated. Phase 2 must make the deployed mean explicit, versioned, and backtested along the exact deployed path.

| Correction | v3 behaviour | v3.4 behaviour |
|---|---|---|
| A. Fusion label leakage | origin season ≤ 2018 only; 16-game target could run into 2019+ (92 such pairs) | every target game ≤ 2018 |
| A2. Target semantics | "next 16 games" silently meant next 16 APPEARANCES (spans to 12 years) | primary fit restricted to spans ≤ 730d; long-span variant reported separately |
| B. Opponent adjustment | defense updated after every passer row; league aggregates moved mid-date | all pre-game states read first; one play-weighted update per game-defense; league aggregates advance at date boundaries |
| C. Population | postseason + non-QB passers mixed in | regular season only, QB only, with a drop report |
| E. Intervals | state variance only | state + skill-transition + target sampling noise, all train-fit |

**Population:** regular season only, QB passers only. Base rows: 11,877 QB-games (v3 used 13,222 incl. postseason and non-QB passers).

**Frozen-era T1 sample:** n = 200 pairs, 60 QBs (v3 reported n = 200, 60 QBs on its own population; sample differs because the population changed).
